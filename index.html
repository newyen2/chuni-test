第一次使用？展開查看完整操作教學

整個流程約需一分鐘。請勿直接另外開啟官方網站，必須從本頁的按鈕開啟，兩個頁面才能互相傳送成績。

  1. 從本頁開啟 CHUNITHM-NET

    點擊教學下方的「開啟 CHUNITHM-NET」。若瀏覽器阻擋新視窗，請允許本站顯示彈出式視窗。

  2. 登入官方網站

    在剛開啟的 CHUNITHM-NET 視窗完成登入，並保持該視窗開啟。

  3. 開啟瀏覽器 Console

    回到 CHUNITHM-NET 視窗。Windows／Linux 請按 F12 或 Ctrl + Shift + J； macOS 請按 ⌘ + ⌥ + J，再切換至 Console（主控台）。

  4. 複製並執行 bridge 程式

    按下「複製程式碼」，貼到 CHUNITHM-NET 的 Console，然後按 Enter。

    在 CHUNITHM-NET Console 執行 
    const script = document.createElement("script");

script.src =
    `https://newyen2.github.io/chuni-test/bridge.js?t=${Date.now()}`;

script.onload = () => {
    console.log("bridge.js 載入完成");
};

script.onerror = error => {
    console.error("bridge.js 載入失敗", error);
};

document.head.appendChild(script);
  5. 回到本頁取得成績

    Console 顯示「CHUNI Simple Bridge 已安裝」及「bridge.js 載入完成」後，回到本頁。 狀態顯示「Bridge 已就緒」時，點擊「取得所有難度成績」；上方篩選器只控制表格顯示哪些難度。

安全提醒： 只在網址為 https://chunithm-net-eng.com/ 的官方頁面執行上述程式， 不要在 Console 貼上他人提供且內容不明的程式，也不要把帳號、密碼或 Token 貼給任何人。
